# Chroniques de Runeterra

Archives de fans, non officielles, de l'univers de *League of Legends* : fiches de champions, régions, histoires réécrites, liens entre personnages, dossiers, parcours de lecture et quiz.

Site : https://syrae0.github.io/chroniques-de-runeterra/

Ce dépôt ne contient que le site construit (branche `gh-pages`). Le code source n'est pas public.

Projet de fan, non affilié à Riot Games. League of Legends et Runeterra sont des marques de Riot Games, Inc. Les images viennent des CDN officiels de Riot et ne sont pas hébergées ici.
